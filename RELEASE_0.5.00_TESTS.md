## B. На колонках — НЕ ВЫПОЛНЕНО

Отметьте модель и прошивку. «✅/❌» ставит тот, кто проверял.

### B1. Обновление и сохранность (Лайт, Мини 2, Мини 1, Станция 2)
1. На 0.4.40 настроить: вход SoundCloud, прокси или обход, ПК, ТВ, EQ, цвета,
   AirPlay-имя. Сохранить копию `/data/opt/soundya/config.json`.
2. Обновить из панели до 0.5.00. Ожидание: «Последнее обновление: 0.4.40 →
   0.5.0, прошло успешно»; все настройки на месте (сравнить с копией —
   добавятся только `config_version`, `music_default`, `led_order`,
   `report_logs`, `macros`); `config.v0.json` лежит рядом.
3. Сломанная сборка: подменить `soundya` в пакете на `#!/bin/sh\nexit 1`
   (переписать `SHA256SUMS`), поставить `sh install.sh`. Ожидание: откат за
   ~2 мин, `update-result` = rolledback, панель это показывает, всё работает.
4. Выдернуть питание во время сохранения настроек (часто жать «Сохранить» и
   выдернуть) ×5. Ожидание: после загрузки настройки целы (или из `.bak`).
5. Перезагрузка: soundya поднимается сам, лог предыдущей загрузки в
   `previous.log`.

### B2. Эквалайзер (на слух, любая модель)
1. EQ выкл → вкл с нулями: громкость не меняется.
2. +6 дБ на 62/125 Гц: басов больше, середина и верх **не тише**, чем при
   выключенном EQ.
3. Громкий трек + +12 дБ на басах: нет треска/хрипа (лимитер «дышит» —
   допустимо).
4. AirPlay с iPhone — то же.

### B3. Кольцо
1. Мини 2: «Цвета не те? Проверка цветов кольца» — канал 1/2/3 горит
   красным/зелёным/синим? Если нет — выбрать увиденное, сохранить, проверить
   оранжевый (#ff7a00), красный, жёлтый, синий. Записать строку
   `led: ring found (…, max_brightness [..])` из лога.
2. Лайт, Мини 1, Мини 3, Luna — цвета как в 0.4.40 (регрессия).

### B5. Багрепорт до настоящего бота
1. На сервере: новый `stats.py`, `SOUNDYA_TG_TOKEN`/`SOUNDYA_TG_CHAT`.
2. С колонки: «Сообщить об ошибке» в AirPlay → «Что будет отправлено» →
   проверить глазами, что нет токена/ключа/контактов → отправить. В Telegram:
   `BUG REPORT #SY-…` + 3 файла (и скриншот, если приложен).
3. Отключить сеть колонки → отправить отчёт → «ждёт отправки» → перезагрузить
   колонку → включить сеть → в течение минуты — «доставлен».
4. Старая панель (кэш браузера) «Написать автору» — тоже доходит (FEEDBACK).

### B6. Безопасность
1. С другого компьютера в сети открыть страницу на произвольном сайте, которая
   делает `fetch('http://<колонка>:8765/api/cmd', {method:'POST', body:'stop', mode:'no-cors'})`.
   Ожидание: музыка не остановилась, в логе `web: refused POST /api/cmd`.
2. Панель по IP, по `soundya.local`, по имени роутера (`*.lan`, `*.home`)
   — все кнопки работают. Если используете своё имя — проверить
   `SOUNDYA_WEB_HOSTS`.

### B7. Новые функции P1/P2
1. Чистая установка: через ~30 с после старта Алиса называет адрес панели, кольцо
   «наполняется» и гаснет; после перезагрузки — молчит; после обновления —
   «Саундя обновлена до версии …» один раз.
2. Мастер первой настройки на чистой установке; выбранное включено, остальное нет.
3. Приглушение: на ПК с soundya-pc позвонить в Telegram Desktop/Zoom — музыка
   SoundCloud и AirPlay тише, после звонка — как была. Видео в браузере не
   приглушает. В `%LOCALAPPDATA%\soundya-pc\log.txt` — строки `duck: start/end`.
   Голос: «приглуши звук», «верни громкость», «отключи автоматическое приглушение».
4. Сценарий «включи кино»: разбудить ТВ → подождать 5 с → открыть приложение
   из загруженного списка; «Проверить» и голосом. «Закрыть приложение».
5. PIN: установить, открыть панель с телефона — смотреть можно, менять — после PIN;
   `adb shell soundya pin off`.
6. Вход SoundCloud: выйти на soundcloud.com (токен перестаёт работать) →
   в панели «Вход в SoundCloud устарел»; новый токен — остальные настройки на месте.

### B8. Голосовая установка, анимации, вход SoundCloud, «Где играет», вид
1. Чистая установка: кольцо «загружается» (Лайт — зоны по очереди, Мини — бегущий
   огонёк; на Мини 3 / Plum / Pickle — крутилка на часах); Алиса называет адрес и
   просит говорить «повтори адрес»; кольцо дышит, на часах бегут части IP.
2. «Алиса, повтори адрес» — повторяет (и позже, в любое время).
3. Панель → мастер → «Начать установку»: Алиса «продолжаем на странице», кольцо
   заполняется по шагам; «Готово» — «Спасибо, что используете саундя», вспышка/
   радуга; на часах «HI», затем обычное время.
4. SoundCloud: вход сохранён → подождать сутки работы — не слетает. Закладка на
   soundcloud.com переносит вход в панель (если SoundCloud прячет cookie —
   закладка скажет об этом, тогда вручную).
5. «Где играет» → «Здесь» на компьютере: музыка звучит в браузере с того же места,
   колонка затихла; «дальше»/пауза из панели и голосом; второй человек видит
   «звучит в браузере» и может «Вернуть звук на колонку»; закрыть вкладку —
   колонка зазвучала.
6. Вид: все вкладки на телефоне и компьютере, тёмная тема, «Вид» → палитры,
   скорость, «Без движения».
7. Сервер: `stats.py --selftest` → сообщение и 3 файла в боте; затем отчёт с колонки.
