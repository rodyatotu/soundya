# Сервер soundya: статистика + анонимная обратная связь

`stats.py` считает работающие колонки (значок «работает на N колонках») и
пересылает анонимные отзывы из веб-панели в Telegram-бота. Только стандартная
библиотека Python 3.8+. IP-адреса не хранятся и не логируются.

## Быстрая установка (без домена, по IP, HTTP)

```
scp -r server root@<vps>:/root/soundya-stats
ssh root@<vps> sh /root/soundya-stats/install.sh
```

## Отчёты об ошибках и обратная связь в Telegram

С 0.5.00 колонка шлёт отчёты на `POST /report`: сервер отправляет боту одно
сообщение `BUG REPORT #SY-…` (версия, модель, раздел, описание, ожидалось/
произошло) и в ответ на него — файлы `system.log`, `error.log`,
`diagnostics.json`, скриншот. Один и тот же номер отчёта доставляется один раз
(колонка повторяет попытки, пока не получит 200; доставленные номера хранятся в
таблице `reports`). Старый `POST /feedback` (0.4.40) работает как раньше.
**Проверить, что отчёты доходят до бота** (на сервере, после установки):
```
set -a; . /etc/soundya-stats.env; set +a
python3 /root/soundya-stats/stats.py --db /tmp/selftest.db --selftest
```
В Telegram придёт `BUG REPORT #SY-…` и три файла; в консоли — `selftest …: 200 ok`.
Затем полный путь с колонки: панель → «Сообщить об ошибке» → «Отправить»; в
«Обновления» → «Обратная связь» статус станет «доставлен».

Ограничение частоты: 1 отчёт в 20 с с одного адреса и 30 в час всего; за Caddy
адрес берётся из `X-Forwarded-For`. Неудачная доставка (Telegram недоступен)
лимит не тратит.

1. У **@BotFather** в Telegram: `/newbot` → получите токен вида `12345:AA...`.
2. Узнайте свой chat id: напишите **@userinfobot** `/start` — пришлёт число.
3. Один раз напишите своему боту любое сообщение (иначе он не сможет вам писать).
4. Установите сервер с токеном и chat id:
   ```
   SOUNDYA_TG_TOKEN='12345:AA...' SOUNDYA_TG_CHAT='123456789' sh install.sh
   ```
   Секреты лягут в `/etc/soundya-stats.env` (права 600), в git не попадают.
   Пока они не заданы, кнопка в панели отвечает «обратная связь недоступна».

## HTTPS и анонимность (рекомендуется)

Чтобы весь трафик колонка↔сервер шифровался, а IP сервера был скрыт:

1. **Домен.** Купите дешёвый домен, у регистратора включите WHOIS-privacy.
2. **Cloudflare** (бесплатно): добавьте домен, A-запись на IP сервера, оранжевое
   облако (proxied). Снаружи виден только IP Cloudflare, ваш — скрыт, плюс защита
   от DDoS. SSL/TLS mode → Full (strict).
3. **Caddy** на сервере для HTTPS к origin: см. `Caddyfile` (подставьте домен).
   Caddy сам получит сертификат Let's Encrypt.
4. Поставьте сервер так, чтобы он слушал только localhost (наружу — Caddy):
   ```
   HOST=127.0.0.1 SOUNDYA_TG_TOKEN='...' SOUNDYA_TG_CHAT='...' sh install.sh
   ```
   Прямой порт 8787 закройте фаерволом: `ufw deny 8787`.
5. В soundya поменяйте адрес сервера на домен и пересоберите:
   ```
   SOUNDYA_STATS_URL='https://stats.ВАШ-ДОМЕН/ping' sh scripts/build-mac.sh
   ```
   И в `README.md` поменяйте ссылку значка на `https://stats.ВАШ-ДОМЕН/`.

После этого колонки ходят на домен по HTTPS, реальный IP сервера скрыт за
Cloudflare, токен бота — только в env-файле на сервере.
