Версии

Что такое soundya

SoundCloud прямо на Яндекс Станции — голосом Алисы, без телефона и компьютера.

Как это работает

1
Скажите Алисе

«Алиса, включи Bonobo в саундклауде»

2
soundya ловит команду

и играет трек напрямую из SoundCloud, минуя Яндекс Музыку.

3
Управляйте как удобно

голосом или из веб-панели: пауза, следующий, лайки, громкость.

Что умеет

SoundCloud голосомРекомендации, лайки, плейлисты, поиск по голосу.
AirPlayСтанция становится AirPlay-колонкой для iPhone и Mac.
Подсветка под музыкуКольцо светится в такт — бас, середина, верха (Ambilight).
Эквалайзер10 полос для SoundCloud и AirPlay прямо из панели.
ПК, ТВ и Telegram«Открой телеграм», «включи проектор», сообщения с компьютера.
Обход блокировокВстроенный zapret/zapret2 — когда SoundCloud режут по имени сайта.

Поставить себе

soundya — открытый проект. Нужен root на Станции; всё остальное делает установщик.

Открыть на GitHub

Через Luna/YAM: yam install rodyatotu/soundya
