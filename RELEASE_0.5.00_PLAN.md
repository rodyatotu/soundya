# RELEASE 0.5.00 — ПЛАН

Редакция 2. Основано на `RELEASE_0.5.00_AUDIT.md`. Структура P2/P3 — из первой
редакции автора (`520837d`), с поправками.

Принципы: модульность; у каждой функции — backend, панель, обработка ошибок,
лог, настройка, выключатель, документация и кнопка «Сообщить об ошибке» (модуль
добавляется в `report.rs::MODULES`); старые конфиги работают; ничего не
имитируем; на колонке не проверено — так и пишем.

Поля: **Файлы** · **Зависит** · **Риски** · **Готово, когда** · **Тест**.

### P1.1 Настоящий Telegram-путь багрепортов на сервере
- Файлы: `server/stats.py`, `server/install.sh`.
- Готово: на `195.209.211.30:8787` развёрнут новый `stats.py`, задан бот;
  отчёт с колонки приходит сообщением + файлами; повтор не дублируется.
- Риски: сервер отдаёт HTTP без TLS — отчёты идут открытым текстом (секреты
  вырезаны, но логи читаемы по пути). Рекомендация из `server/README.md`:
  домен + Caddy + `SOUNDYA_STATS_URL=https://…` при сборке.

### P1.2 SoundCloud: вход без ручного копирования

- Тест: юнит на `token_bad` → статус; ручной вход.

  нет (не «100+» по умолчанию). Закрывается навсегда (localStorage).

### P1.7 Onboarding и мастер первой настройки
- Голосовое приветствие с адресом панели (IP из `ip -4 addr` / `mdns::own_ip`),

- Мастер в панели: модули по шагам (SoundCloud, музыка по умолчанию, ПК, ТВ,
  AirPlay, подсветка), невыбранное — выключено; шаг про DHCP reservation.
- Анимации — только то, что умеет кольцо конкретной модели (`led::info()`).

### P1.8 Smart Audio Ducking по внешним событиям
- Источники событий без микрофона: агент ПК (звонок Teams/Telegram Desktop
  по окну/аудиосессии Windows — API `IAudioSessionManager2`), Android-телефон —
  только через отдельное приложение/Tasker-вебхук (стоит оценить).
- Колонка: `POST /api/duck {source, kind: call|notify, state: start|end}`
  (с ключом), счётчик активных событий, уровень и приоритеты из настроек,
  возврат к **громкости до события**, если пользователь не менял её вручную.
- Существующий `Duck` (под голос Алисы) — расширить, не дублировать.
- Голос: «приглуши/верни громкость/отключи автоприглушение».
